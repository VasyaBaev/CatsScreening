# Workflow выполнения шага (обязательно)

Этот workflow описывает, как агент выполняет **любой** запрос в проекте CatsScreening.

## 0) Выбор номера шага
Перед началом работы:
1) Посмотреть `.tmp/reports/` и найти последний `step-XXX_*.md`.
2) Следующий шаг = `XXX + 1`.
3) В течение шага вести заметки, в конце — оформить отчёт.

## 1) Сбор контекста
- Быстро определить, каких данных не хватает для корректной реализации.
- Если критически не хватает информации (и нельзя безопасно предположить) — задать пользователю уточняющие вопросы **до** реализации.

## 2) Исследования: сначала локально, потом интернет
Если задача требует научных источников/алгоритмических обоснований:
1) Сначала открыть `docs/research/research-map.md`.
2) Если ответа нет — искать в интернете.
3) Если найденный материал нужен проекту “в долгую”:
   - сохранить локальную копию в `docs/research/papers/` (предпочтительно PDF) или `docs/research/notes/` (если PDF недоступен),
   - обновить `docs/research/research-map.md`: добавить ссылку, путь к локальной копии и краткую выжимку.

## 3) Подтверждение понимания
Кратко зафиксировать:
- как агент понял задачу,
- какие допущения делает,
- какие ограничения/риски видит.

## 4) План
Выдать краткий план (3–7 пунктов) и только после этого приступать к реализации.

## 5) Реализация
- Вносить изменения минимально и целенаправленно.
- Комментарии в коде — на русском, развернуто.
- Кодировка UTF‑8, переносы строк CRLF (см. `.editorconfig`).

## 6) Проверка
По возможности:
- `npm run typecheck`
- `npm run build`
- минимальные smoketests (запуск dev‑серверов)

## 7) Итог в чате
В ответе пользователю обязательно:
- что сделано,
- какие файлы изменены,
- какой результат,
- какие риски,
- следующие шаги.

## 8) Отчёт по шагу (обязательно)
Создать файл: `.tmp/reports/step-XXX_<короткое-название>.md`

Рекомендуемый шаблон:

```md
# Step XXX — <название>
Дата: YYYY-MM-DD

## Запрос / цель

## Понимание задачи

## План

## Сделано

## Изменённые файлы

## Команды (что запускалось)

## Риски / замечания

## Следующие шаги
```
