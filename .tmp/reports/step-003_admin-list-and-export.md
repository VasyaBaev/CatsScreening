# Step 003 — Админка MVP: список кейсов + экспорт CSV
Дата: 2026-04-16

## Запрос / цель
Следующий шаг после Step‑002:
- Добавить минимальный функционал админки для MVP:
  - список кейсов,
  - выгрузка CSV.
- После шага сделать git commit.

## Понимание задачи
Из документов проекта админка требуется уже на Этапе 1:
- просмотр кейсов (метаданные, результат, ссылки на фото),
- выгрузка (CSV) для анализа и приёмки.

На этом шаге делаем самый простой “сквозной” путь:
DB → API → UI.

## План
1) Добавить админские эндпоинты API:
   - `GET /api/admin/cases`
   - `GET /api/admin/export.csv`
2) Подключить эндпоинты в Fastify.
3) Сделать UI `/admin` со списком и кнопкой экспорта.
4) Обновить документацию API.
5) Проверить `typecheck/build`.
6) Сделать git commit.

## Сделано
- Backend:
  - Добавлен маршрут `GET /api/admin/cases` (пагинация offset/limit).
  - Добавлен маршрут `GET /api/admin/export.csv` (CSV всех кейсов).
  - Роуты подключены в реестр `apps/api/src/routes/index.ts`.
- Frontend:
  - `/admin` теперь загружает список кейсов и показывает таблицу.
  - Добавлена ссылка “Экспорт CSV” (`/api/admin/export.csv`).
- Docs:
  - Добавлен файл `docs/api/endpoints.md` и ссылка на него из `README.md`.

## Риски / замечания
- Эндпоинты админки пока без авторизации (на проде обязательно закрыть).
- CSV сейчас генерируется целиком в памяти (для больших объёмов нужен streaming/батчинг).
- Папка с исходными фото‑датасетами `sources/Photos/` исключена из git (`.gitignore`), чтобы не раздувать репозиторий (~73MB).
