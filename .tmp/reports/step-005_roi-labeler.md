# Step 005 — ROI labeler (полуручной режим)
Дата: 2026-04-16

## Запрос / цель
Реализовать Step-005 из плана: добавить инструмент/страницу для разметки ROI прямоугольником и экспортировать `roi-labels-v1.json`.

## Понимание задачи
- Нам нужен “полуручной” этап, чтобы стабилизировать признаки на маленьком датасете (уменьшить влияние края лотка, фона и т.п.).
- ROI должен храниться в относительных координатах 0..1 и быть привязан к ключу, совпадающему с путями из `manifest-v1.json`.

## План
1) Добавить страницу в `apps/web` с file picker (directory mode) и canvas/overlay выделением прямоугольника.
2) Сформировать ключи как `sources/Photos/PH/<...>` из `webkitRelativePath`.
3) Реализовать экспорт/импорт JSON.
4) Задокументировать workflow в `docs/dataset/`.

## Сделано

- Добавлена документация по датасету и ROI-разметке: `docs/dataset/README.md`.

## Риски / замечания
- `webkitdirectory` работает в Chromium‑браузерах (Chrome/Edge). В Safari может не поддерживаться; для него остаётся выбор файлов вручную.
- Если выбирать отдельные файлы (без директории), ключи будут без pH‑подпапки (т.к. браузер не отдаёт путь), поэтому для датасета рекомендуется directory picker.
