# agent.md — правила совместной работы

Этот документ — “контракт” совместной работы по проекту CatsScreening.

## 1) Обязательный workflow
Каждая задача выполняется по одному и тому же сценарию (шагу). Описание шага:
- `.codex/workflows/skills-workflow.md`

Важно: **каждое действие/каждый шаг должен следовать workflow** и завершаться отчётом в `.tmp/reports/`.

## 2) Язык
- Коммуникация: русский язык.
- Комментарии в коде: русский язык, развернуто (назначение модуля/функции, входы/выходы, важные переменные, причины решений).

## 3) Кодировка / переносы строк
- Кодировка: UTF‑8.
- Переносы строк: CRLF (Windows/PowerShell).
- Настройки фиксируются в `.editorconfig` и `.gitattributes`.

## 4) Исследования: “сначала локально”
Перед любым поиском в интернете по исследованиям/алгоритмам:
1) Сначала читать `docs/research/research-map.md`.
2) Если нужно добавить новое исследование — сохранять локальную копию в `docs/research/papers/` или `docs/research/notes/` и добавлять путь в карту.

## 5) Отчёты по шагам
- Папка: `.tmp/reports/`
- Имя: `step-XXX_<короткое-название>.md` (сквозная нумерация)
