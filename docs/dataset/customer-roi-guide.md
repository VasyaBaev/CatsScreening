# Инструкция заказчику: ROI-разметка фотографий

## Что нужно разметить
Размечать нужно не лоток целиком, а область наполнителя, по которой реально должен читаться цвет реакции.

Выделяйте:
- основную рабочую зону наполнителя, где виден цветовой результат pH;
- крупный однородный участок, а не маленькую точку;
- центральную или самую чистую часть реакционной области;
- влажное/окрашенное пятно, если реакция локальная.

Не включайте:
- бортики и стенки лотка;
- фон за пределами наполнителя;
- сильные блики;
- тени от телефона или рук;
- грязные/нерепрезентативные края;
- пустой пластик лотка.

Практическое правило: лучше выделить область чуть меньше, но чище, чем большую область с бортиком, тенью или бликом.

## Зачем это нужно
Алгоритм считает цветовые признаки по выбранной ROI-области. Если анализировать весь кадр, в расчёт попадут лоток, фон, тени и блики. Тогда модель будет учиться не pH, а случайным условиям съёмки.

ROI-разметка нужна, чтобы первая калибровка была стабильной: сравнивался цвет наполнителя, а не цвет пластика лотка или освещения.

## Как запустить оснастку
Откройте PowerShell в папке проекта и выполните:

```powershell
npm run roi:start
```

Если зависимости ещё не установлены, скрипт сам выполнит `npm install`.

После запуска откроется страница:

```text
http://127.0.0.1:5173/tools/roi-labeler
```

## Как разметить
1. Нажмите “Выбрать папку (рекомендуется)”.
2. Выберите папку `sources/Photos/PH`.
3. На каждом фото выделите прямоугольник с чистой областью наполнителя.
4. Нажмите “Скачать JSON”.
5. Сохраните файл в проект как `data/dataset/roi-labels-v1.json`.

## Как проверить
После сохранения файла выполните:

```powershell
npm run roi:check
```

Проверка должна показать:
- `totalPhotos`: 45;
- `missing`: 0;
- `invalid`: 0.

## Как отправить разметку обратно в GitHub
После успешной проверки выполните:

```powershell
npm run roi:publish
```

Скрипт проверит разметку, сделает коммит только файла `data/dataset/roi-labels-v1.json` и выполнит `git push`.

Если `git push` попросит авторизацию GitHub, войдите под аккаунтом, которому выдан доступ к репозиторию.
