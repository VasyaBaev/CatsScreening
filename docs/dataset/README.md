# Датасет и разметка (MVP)

Этот раздел описывает “инженерный” контур работы с первой пачкой фото, не изменяя исходники в `sources/`.

## 1) Где лежат исходные фото
- `sources/Photos/PH/`

> Важно: папку `sources/` считаем read-only (не переносим и не переименовываем).

## 2) Manifest + blind set
Manifest и фиксированная контрольная выборка (blind set) лежат в:
- `data/dataset/manifest-v1.json`
- `data/dataset/blind-set-v1.json`

Сгенерировать заново (из корня репозитория):

```powershell
npx tsx scripts/dataset/build-manifest.ts
```

## 3) Разметка ROI (полуручной режим)
На старте мы фиксируем ROI прямоугольником для каждого изображения, чтобы алгоритм анализировал **только область реакции** и меньше зависел от края лотка, фона и ракурса.

### 3.1 Где находится инструмент
В веб‑приложении есть внутренняя страница:
- `/tools/roi-labeler`

Запуск (dev):

```powershell
npm run dev:web
```

Далее открыть в браузере:
- `http://127.0.0.1:5173/tools/roi-labeler`

### 3.2 Как размечать
1) Нажать “Выбрать папку (рекомендуется)”.
2) Выбрать директорию `sources/Photos/PH` (именно папку `PH`).
3) На каждом фото выделить ROI прямоугольником.
4) Нажать “Скачать JSON” и сохранить файл как:
- `data/dataset/roi-labels-v1.json`

### 3.3 Формат `roi-labels-v1.json`
Файл представляет собой JSON:

```json
{
  "version": 1,
  "generatedAt": "2026-04-16T00:00:00.000Z",
  "items": {
    "sources/Photos/PH/6/(6) окно  белый.jpg": { "x": 0.1, "y": 0.2, "w": 0.6, "h": 0.4 }
  }
}
```

- Ключи — repo‑relative пути к изображениям (как в manifest).
- `x/y/w/h` — относительные координаты 0..1 относительно ширины/высоты кадра.
