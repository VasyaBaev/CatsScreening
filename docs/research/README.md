# Research / база знаний

Эта папка — “локальная база знаний” по исследованиям, на которые опираемся в проекте.

## Основной файл
- `docs/research/research-map.md` — карта исследований: ссылки, выжимки, применение, пути к локальным копиям.

## Правило работы
Перед поиском в интернете по исследованиям/алгоритмам:
1) Сначала читать `docs/research/research-map.md`.
2) Если в карте нет ответа — искать в интернете.
3) Если материал нужен проекту “в долгую” — сохранять локальную копию и добавлять запись в карту.

## Где хранить локальные копии
- `docs/research/papers/` — PDF/HTML локальные копии статей
- `docs/research/notes/` — наши конспекты/выжимки (если PDF недоступен)
